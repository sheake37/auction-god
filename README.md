# 경매의 신! (서버 버전)

친구들이 각자 컴퓨터/폰에서 접속해서 직접 입찰하는 실시간 경매 게임입니다.

## 내 컴퓨터에서 실행
1. Node.js 18 이상 설치 (https://nodejs.org)
2. 이 폴더에서 터미널을 열고:
   ```
   npm install
   npm start
   ```
3. 브라우저에서 http://localhost:3000 → "방 만들기"
4. 친구들에게 공개 주소가 필요하면 터미널을 하나 더 열고 `npx ngrok http 3000`
   (나온 https 주소를 친구들에게 보내세요)

## 무료 호스팅 (Render 예시)
1. 이 폴더를 GitHub 저장소로 올립니다.
2. Render에서 New → Web Service → 저장소 연결
3. Build Command: `npm install` / Start Command: `npm start`
4. 배포가 끝나면 나오는 주소를 친구들에게 공유
   (무료 플랜은 한동안 쓰지 않으면 잠들어서 첫 접속이 느릴 수 있어요)

## 게임 방법
- 호스트: 방 만들기 → 라운드/테마/물품/사진/시작 금액 준비 → 친구들이 들어오면 "경매 시작!"
- 친구들: 링크 또는 방 코드로 접속 → 이름 입력 → 참가
- 입찰·대출은 각자 자기 카드에서, 낙찰·다음 단계는 호스트만 진행합니다.

## 참고
- 방 정보는 서버 메모리에 있어서 서버를 재시작하면 사라집니다. (6시간 지난 방은 자동 정리)
- 호스트 설정은 호스트 브라우저에 자동 저장되어 다음 방에서도 이어집니다.
- 게임이 시작된 뒤에는 새 참가자가 들어올 수 없습니다. (끊긴 참가자는 같은 기기로 재접속 가능)
